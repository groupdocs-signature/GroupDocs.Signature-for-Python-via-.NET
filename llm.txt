**GroupDocs.Signature for Python via .NET**

Python SDK to **sign, verify, search, and remove digital signatures** in 90+ file formats (PDF, Word, Excel, Images). Supports barcode, QR code, image, text, form field, and certificate-based (X.509, PKCS#7) signatures.

## Key Features

- Add signatures to PDFs, DOCX, XLSX, PPTX, PNG, etc.
- Digital signing with certificates (.pfx)
- Verify and remove existing signatures
- Support for QR, barcode, image, stamp, metadata, and text signatures
- Python 3.6+ / Flask / Django / async support
- Works on Windows, Linux, macOS, Docker, Cloud

## Install

```bash
pip install groupdocs-signature-net
```

## Code Snippet

```python
from groupdocs.signature import Signature
from groupdocs.signature.options import DigitalSignOptions

with Signature("file.pdf") as sign:
    opts = DigitalSignOptions("cert.pfx")
    opts.password = "pass"
    sign.sign("signed.pdf", opts)
```
